# Quality Rubric

Score each generated skill from 0 to 100.

## Architecture, 20 points

- 0-5: Skill idea is vague or single-use.
- 6-10: Basic structure exists but lacks decision logic.
- 11-15: Inputs, outputs, workflow, and tools are clear.
- 16-20: Modular system architecture with automation and multi-agent paths.

## SKILL.md Quality, 20 points

- 0-5: Prompt-like, not installable.
- 6-10: Includes role and workflow but lacks full operational rules.
- 11-15: Includes frontmatter, triggers, workflow, validation, outputs.
- 16-20: Production-grade, reusable, concise, and context-aware.

## Validation And Safety, 20 points

- 0-5: No meaningful validation.
- 6-10: Mentions checks but lacks enforcement.
- 11-15: Has input checks, confidence rules, fallbacks.
- 16-20: Includes source freshness, hallucination controls, scoring, high-stakes safeguards.

## Integration And Automation, 15 points

- 0-5: No tool strategy.
- 6-10: Lists tools without routing logic.
- 11-15: Recommends appropriate APIs, MCP tools, automations, and script opportunities.

## Scalability, 15 points

- 0-5: Single-user or one-off workflow only.
- 6-10: Some reuse guidance.
- 11-15: Multi-agent, memory, queue, cloud, and team usage guidance.

## Output Clarity, 10 points

- 0-3: Hard to implement.
- 4-7: Mostly clear but missing structure.
- 8-10: Exact, complete, and ready to implement.

Minimum acceptable score: 85.

If the skill scores below 85, revise before delivery.
