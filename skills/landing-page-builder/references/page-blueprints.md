# Page Blueprints

## Opt-in

Hero promise → asset preview → 3–5 outcomes → compact form → trust/privacy → CTA.

Use for cold traffic and a clear value exchange. Keep phone optional unless qualification or channel strategy justifies it.

## Lead-magnet delivery

Confirmation → download/access → expectation setting → one next step → support/privacy.

Do not hide the promised asset behind another conversion.

## Webinar, workshop or event

Outcome/date/location → learning outcomes → audience fit stated without protected-class targeting → host proof → logistics → registration → reminders expectation → FAQ.

Use only genuine capacity or deadline language.

## Consultation booking

Outcome → what happens on the call → fit criteria → proof → calendar → FAQ → confirmation.

Clarify duration, preparation and follow-up.

## Application

Outcome and why application exists → offer → fit/non-fit based on business needs → proof → form → post-application expectations.

Collect only information necessary for qualification.

## Sales or VSL

Promise → problem/context → mechanism → offer → proof → demonstration → pricing/terms → risk reversal when genuine → FAQ → purchase/application.

Do not manufacture stacked values or guarantees.

## Home valuation or equity

Local homeowner question → what report contains → difference between estimate, CMA and appraisal → address/contact form → privacy → process after submission → agent proof.

Do not promise an instant or exact valuation unless the system actually provides it.

## Open house RSVP

Verified property/date/time → objective features → RSVP → attendance details → representation/privacy disclosures when applicable → confirmation and directions.

## Listing showcase

Verified hero facts → media → features → location context from neutral sources → costs/disclosures → showing inquiry → availability disclaimer.

## New construction or property list

Market-specific promise → verified community/property options → comparison → incentives with date → recurring costs → buyer-agent/process explanation → qualification form → consultation/tour.

## Recruiting or community

Agent problem → value proposition → verified program/community proof → what participation includes → fit → event/application/conversation CTA → FAQ.

Keep recruiting brand separate from consumer real estate brand.

## Thank-you

Confirmation → promised next step → expected timing → delivery or calendar → optional secondary action → support contact → tracking event.
