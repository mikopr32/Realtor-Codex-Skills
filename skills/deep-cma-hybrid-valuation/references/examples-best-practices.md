# Example Prompts And Best Practices

## Example Prompts

```text
Use $deep-cma-hybrid-valuation to create a seller presentation CMA for 123 Main St, Orlando, FL 32801. It has 4 beds, 3 baths, 2,450 sqft, built in 2005, 0.22 acre lot, pool yes, 2-car garage, good condition, renovated kitchen in 2022. Use sold comps from the last 6 months. Zillow: <link>.
```

```text
Use $deep-cma-hybrid-valuation to validate whether our proposed list price of $650,000 is defensible. Objective: seller presentation. Include active competition and historical appreciation from last sale.
```

```text
Use $deep-cma-hybrid-valuation for a reduction strategy. The home has been listed 45 days with low showing activity. Compare sold comps, actives, pending, and appreciation value.
```

## Best Practices

- Always start with intake validation.
- Use ranges and confidence levels, not false precision.
- Explain comp exclusions.
- Avoid over-crediting upgrades unless documented.
- Use active competition to pressure-test the recommended price.
- Keep seller language clear, strategic, and calm.
- Show limitations without weakening confidence unnecessarily.
- Make the final recommendation practical: list price, expected risk, and defense narrative.
